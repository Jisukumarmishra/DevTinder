Mongoose is a Node.js library that makes working with MongoDB easier.
npm install mongoose
const mongoose = require("mongoose");

const userSchema = new mongoose.Schema({
    firstName: String,
    age: Number
});

const User = mongoose.model("User", userSchema);


| MongoDB                   | Mongoose                                   |

| Database                  | ODM (Object Data Modeling) library         |

| Runs as a separate server | Runs inside your Node.js application       |
| No schema required        | Supports schemas and validation            |

Indexes In MongoDb:==
Indexes are special data structures that help the database find records quickly without scanning the entire table or collection.
They improve read, search, filtering, sorting, and join performance. However, indexes consume extra storage and make insert, update,
and delete operations slower because the index must also be maintained
